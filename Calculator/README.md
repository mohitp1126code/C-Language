### 🧮 Calculator

A simple and user-friendly calculator developed using C language with the `switch` statement.

## ✨ Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Modulus (%)
- Division by zero handling
- Modulus by zero handling
- Invalid choice handling
- Results displayed up to 2 decimal places

## 🛠️ Technologies Used

- Switch Case
- If-Else Statements
- Arithmetic Operators
- Standard Input/Output
